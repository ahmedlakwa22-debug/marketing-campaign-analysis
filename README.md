
# 📊 Marketing Campaign Data Analysis

This is a comprehensive data analysis project using Python and Pandas, focused on exploring the effectiveness of different marketing campaigns across various markets, store ages, and promotional strategies.

---

## 🔍 Project Objectives

- Identify the most effective promotion types.
- Explore how market size and store age affect sales.
- Analyze weekly sales trends.
- Detect top-performing store locations.
- Classify stores into performance clusters using K-Means.

---

## 🧰 Tools Used

- **Python 3**
- **Pandas, NumPy**
- **Matplotlib, Seaborn**
- **Scikit-learn (KMeans, PCA)**
- **SciPy (ANOVA test)**
- **Jupyter Notebook**

## 🧠 Key Insights

- Promotion **1** generated the highest average sales.
- Promotion **2** consistently underperformed.
- Promotion **3** worked best in large markets and newer stores.
- Store clusters showed distinct patterns in sales and features.
